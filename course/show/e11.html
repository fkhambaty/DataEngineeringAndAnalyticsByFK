Said out loud

The lock is not magic.

Unmapped means empty

Inside the app, a user missing from APP_USER sees nothing. Outside it, transformer, analyst and ML still see the bank. That is the ELSE branch.

The payment names one customer

fct_transactions stores primary_customer_id. A joint holder who is not primary does not see that row. The bridge still lists them, filtered to their own id.

No chat in this region

A trial can build every table and still refuse Cortex. Run the four questions in analyses/card_questions.sql, logged in as each user. The policy does not need Cortex.

The demo is prod

The attach hook runs only when the target is prod. Dev has no persona grants and no policies. CREATE IF NOT EXISTS will not edit a policy that already exists: the script ends with ALTER … SET BODY.
