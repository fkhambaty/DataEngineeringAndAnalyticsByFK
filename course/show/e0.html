01_source_postgres/04_cdc_triggers.sql

Two triggers keep the bookmark honest.

TRIGGER 1

cdc.set_updated_at()

Before every update, stamp the row. The bookmark only sees a change that moves updated_at.

updated_at → now()
trg_set_updated_at · BEFORE UPDATE
TRIGGER 2

cdc.log_delete()

After every delete, write the key to cdc.deleted_records. A vanished row cannot move a bookmark.

core.accounts row → gone
trg_log_delete · AFTER DELETE
what the bookmark still has to handle
late commit        → INGEST_LAG_SECONDS = 10 re-reads the edge
two changes, 1 run → only the latest version lands
hard delete        → only cdc.deleted_records remembers it
safety net         → 02_ingestion_python/reconcile_with_pandas.py
