Least privilege

A person gets a role. The role gets the keys.

✗

WRONG

Hand SELECT to a person. The next table is invisible, and you cannot see who was supposed to have access.

GRANT SELECT ON TABLE … TO USER <a person>
✓

RIGHT

Hand the role to the person. Hand the permission to the role. You can see who is allowed to do the job.

GRANT ROLE MERIDIAN_ANALYST TO USER <your_user>;
GRANT SELECT ON … TO ROLE MERIDIAN_ANALYST;

_core__models.yml · stg_postgres__transactions.sql

A key is a label. The test is the lock.

1
Primary and foreign keys

Snowflake records them. A second key still loads. A dangling reference still loads.

2
NOT NULL is enforced

A null in that column fails the write. The primary-key label on the same column does not.

3
dbt tests enforce the key

unique, not_null, relationships. A contract checks names and types. A failed test skips downstream models.

4
Dedupe the batch, then MERGE

Two source rows for one key abort the MERGE. QUALIFY keeps the newest before that statement.
