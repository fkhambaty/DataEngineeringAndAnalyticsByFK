01_values_and_decisions.py

Text in. Numbers, then a decision.

00_python_foundations/01_values_and_decisions.py
source_rows_text = "100000"
warehouse_rows_text = "99998"
source_amount_text = "250000.00"
warehouse_amount_text = "247500.00"
source_rows = int(source_rows_text)
warehouse_rows = int(warehouse_rows_text)
source_amount = float(source_amount_text)
warehouse_amount = float(warehouse_amount_text)
amount_threshold = float("0.01")
row_difference = warehouse_rows - source_rows
amount_difference = warehouse_amount - source_amount
if row_difference == 0 and abs(amount_difference) < amount_threshold:
    status = "PASSED"
else:
    status = "FAILED — rows or posted amounts disagree"
print("Reconciliation:", status)
1
Quotes make text

An environment variable arrives as text, even when it looks like a number.

2
Cast before arithmetic

int() for counts. float() for amounts and for the 0.01 threshold.

3
How far apart

Warehouse minus source. Negative means the warehouse is short.

4
Exactly one branch

Rows must match, and the amount gap must be under one hundredth. print shows the result.

1
One branch

PASSED or FAILED. Never both. The real loader uses the same shape for a quiet table versus a load.

2
Once per selected table

customers is in the list. hot_only keeps transactions and card_authorizations.

3
Change the counter

This while stops at 3. The extractor loops forever only when you pass --loop. Without += 1, a while never ends.

02_loops_and_functions.py

A function is a job with a name.

02_loops_and_functions.py
def tables_to_load(all_tables: list[str], hot_only: bool) -> list[str]:
    if hot_only:
        return [name for name in all_tables if name in {"transactions",
            "card_authorizations"}]
    return all_tables
def main() -> None:
    tables = ["customers", "transactions", "card_authorizations"]
    for table in tables_to_load(tables, hot_only=True):
        print(describe_batch(1, table))
if __name__ == "__main__":
    main()
1
Inputs in the parentheses

all_tables and hot_only. The arrow is a label for readers, not a command.

2
return sends one answer

A shorter list, or every table. The caller prints that answer.

3
main is the front door

Read main() first in the extractor too. The jobs sit in named functions underneath.

4
Run only when executed

Importing the file does not call main(). Running the file does.

A flag becomes a value
