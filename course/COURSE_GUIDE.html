The three layers in this project

Bronze

MERIDIAN_RAW.POSTGRES_*
  • Exactly what Python delivered
  • One VARIANT column per row, plus when and which batch
  • Append only: every version, even deleted rows
  • Built by: pg_to_snowflake.py

Silver

MERIDIAN_ANALYTICS.STAGING · INTERMEDIATE · SNAPSHOTS
  • Typed columns, renamed
  • Newest version per id; deletes removed
  • History kept by snapshots
  • Built by: dbt

Gold

MERIDIAN_ANALYTICS.MARTS
  • Kimball star: facts and dimensions
  • Tested, contracted, row policies attached
  • The only layer people and the app read
  • Built by: dbt
